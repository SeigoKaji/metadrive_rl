# lookahead_learning の差分移植を実施してください

このファイルを読んで実施するよう依頼されたら、以下を実行してください。
これは調査・説明だけの依頼ではなく、バックアップ、差分適用、軽量検証、結果報告までの実施依頼です。
追加の長文プロンプトや元のチャットは不要です。単一エージェントで進めてください。

1. このファイルと同じ配布フォルダ内の [docs/copilot_porting_prompt.md](docs/copilot_porting_prompt.md) を全文読み、その手順を実施してください。必要な設計・接続資料も同梱されています。
2. このファイルのあるフォルダ（通常は `lookahead_learning_update/`）を移植元、対象プロジェクトの既存 `lookahead_learning/` を移植先として比較してください。移植元と移植先が同じ実体なら適用を行わず、その状態を報告してください。
3. 既存の独自変更と未コミット差分を先にバックアップし、不足差分だけ適用してください。フォルダ全体をコピー・リネームして置換しないでください。通常train/evaluate/factory/workerなどの既存接続を再利用してください。
4. 既存の横加速度報酬の式・有効設定・上限・重みを保持し、時間指定の注視点と等速・一定曲率の予測位置報酬を追加してください。報酬は1回だけ加算し、加速度推定・加速度付き予測は追加しません。
5. 同梱手順の軽量テストと通常CLIの設定読込を確認し、可能なら既存assetsで数stepのsmokeを実行してください。適用済みなら検証だけ行います。最後に変更内容、バックアップ先、検証結果、未検証・保留事項、今回差分だけの戻し方を報告してください。

通常の不足差分は上記の依頼に従って適用し、説明や計画だけで終了しないでください。
判断できない契約や競合はその箇所だけ保留して報告し、他の確認済み作業は進めてください。
移植先でのcommit/pushは、その利用者から明示的な指示がある場合だけ行ってください。
